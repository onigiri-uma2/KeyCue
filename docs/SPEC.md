# KeyCue 仕様書 (SPEC.md)

## 1. アプリケーション概要

**KeyCue (キーキュー)** は、『Sky 星を紡ぐ子どもたち』などの15キー楽器演奏UIを持つゲーム向けに設計された、Android用フローティング演奏支援・練習サポートアプリケーションです。

ゲームプレイ中の画面上に透過オーバーレイを重ね、次の打鍵対象キー、タイミング、音ゲー風の落下ノート（Falling Notes）やアプローチサークル、ジャスト演出をリアルタイムにガイドします。
※ 本アプリは自動タップ・自動演奏ツールではなく、ユーザー自身が打鍵練習を行うための視覚的タイミングガイドを提供します。

---

## 2. 動作環境・開発要件

- **プラットフォーム**: Android
- **開発言語**: Kotlin 2.2+
- **UIツールキット**: Jetpack Compose (BOM 2026.02.01+) & Android View (Overlay描画)
- **最低動作要件 (minSdk)**: Android 10.0 (API レベル 29)
- **ターゲットSDK (targetSdk / compileSdk)**: API レベル 37
- **必須権限**:
  - **ユーザー許可が必要な権限**:
    - `他のアプリの上に重ねて表示` (`android.permission.SYSTEM_ALERT_WINDOW`): ゲーム画面上にガイドやコントローラーを表示するために必須
    - `通知の送信` (`android.permission.POST_NOTIFICATIONS`): Android 13 (API 33) 以降で常駐通知を表示するために必須
  - **マニフェスト宣言権限**:
    - `フォアグラウンドサービス実行` (`android.permission.FOREGROUND_SERVICE`): ゲームプレイ中も安定してオーバーレイを常駐動作させるために使用
    - `特殊用途フォアグラウンドサービス` (`android.permission.FOREGROUND_SERVICE_SPECIAL_USE`): Android 14 (API 34) 以降の用途指定（演奏タイミング支援フローティングUI）

## 3. 15キー配置定義

Sky等の演奏UIに準拠した **3段 × 5列 = 計15キー** のマトリクス配置を採用します。

```text
上段: [ 0] [ 1] [ 2] [ 3] [ 4]   (○ 円形ノート)
中段: [ 5] [ 6] [ 7] [ 8] [ 9]   (□ 四角形ノート)
下段: [10] [11] [12] [13] [14]   (△ 三角形ノート)
```

- 各キー座標は画面解像度やアスペクト比に依存しない **正規化座標 (`NormalizedPoint`: x=0.0..1.0, y=0.0..1.0)** で管理します。
- 画面上のピクセル座標は描画時に `viewWidth`, `viewHeight` を乗算して動的に算出します。

## 4. 共通データ構造

### 4.1 NoteEvent (打鍵イベント)
```kotlin
data class NoteEvent(
    val timeMs: Long,  // 楽曲冒頭からの打鍵目標時刻（ミリ秒）
    val key: Int       // 対象キー番号 (0..14)
)
```

### 4.2 SongData (楽曲データ)
```kotlin
data class SongData(
    val title: String,            // 曲名
    val format: SongFormat,       // SKY_STUDIO_JSON または MIDI
    val durationMs: Long,         // 楽曲全体の演奏時間（ミリ秒）
    val notes: List<NoteEvent>    // timeMs昇順にソートされた全打鍵イベント
)
```

## 5. 対応楽曲フォーマット

### 5.1 Sky Studio JSON 形式 (`.json`)
- Sky Studio 公式およびコミュニティ形式の JSON 譜面に対応。
- **暗号化譜面への対応**: 暗号化された譜面（`isEncrypted: true`）は仕様上非対応。検出時は分かりやすいエラーメッセージを表示し、暗号化なしで再エクスポートしたファイルを使用するよう案内。
- **重複ノート除外**: 同一時刻・同一キーの完全重複ノートのみを除外し、異なるキーの和音は完全保持。
- **演奏時間算出**: 最終ノート時刻にリリース余韻を加算して正確な `durationMs` を算出。

### 5.2 標準 MIDI 形式 (`.mid`, `.midi`)
- **対応規格**: MIDI Format 0（単一トラック）および Format 1（マルチトラック）。
- **テンポマップ**: 楽曲途中のテンポ変更（Set Tempo メタイベント 0x51）に追従し、MIDI Tick を正確なミリ秒へ変換。
- **音域マッピング (`MidiKeyMapper`)**:
  - **自動判定 (AUTO)**: 楽曲中の音階出現頻度から調（メジャー/マイナー）およびオクターブを自動解析し、15キーに最適配置。
  - **手動指定 (MANUAL)**: 基準ルート音（PitchClass C〜B）、スケール種別（Major / Natural Minor / Pentatonic等）、基準オクターブ（2〜6）を自由に固定可能。

## 6. 主要機能仕様

### 6.1 画面フィッティング (キー位置設定)
- **OpenCV 自動検出 (`OpenCvKeyDetector`)**:
  - スクリーンショットからグレースケール変換、ガウシアンブラー、適応的二値化（Adaptive Threshold）。
  - 輪郭抽出と円形度（Circularity: $4\pi \times Area / Perimeter^2$）解析により、正円ボタンおよびダイアモンド(◇)キーを検出。
  - 画面最下部の地面（キャンドル群）や上部メニューを排除するY座標範囲フィルタ。
- **グリッドフィッティング (`GridFitter`)**:
  - 行クラスタリング、ピッチ間隔推定により外れ値を除外。
  - 4隅（Key 0, 4, 10, 14）を基準とした **バイリニア補間（双線形補間）** により、歪みやパースのある配置でも内部11キーを正確に補間。
- **手動微調整 UI (`FittingOverlayView`)**:
  - 4隅ハンドルの直接ドラッグ移動。
  - 微動D-pad（上/下/左/右）によるピクセル単位の精密調整。
  - 「自由変形モード（単独頂点移動）」と「矩形維持モード（対向頂点連動）」の切り替え。

### 6.2 フローティング演奏ガイド (`GuideOverlayView`)
- `SYSTEM_ALERT_WINDOW` によるフルスクリーン透過オーバーレイ（タッチイベント完全透過: `FLAG_NOT_TOUCHABLE`）。
- **VSYNC 同期描画**: Android の `Choreographer` を使用し、フレーム落ちのない滑らかな描画を実現。
- **音ゲー風落下ノート (`FallingNotesRenderer`)**:
  - ノート先読み時間（`noteLeadTimeMs`: デフォルト 300ms、300〜2000ms で変更可能）に合わせて上部からキー位置へ降下。
  - 段ごとに異なる形状（○ / □ / △）と個別カラーカスタマイズ。
- **アプローチサークル (`TimingEffectRenderer`)**:
  - タイミングサークル先読み時間（`approachCircleLeadTimeMs`: デフォルト 200ms、100〜1000ms で変更可能）に合わせて目標キーに向かって収縮するタイミング円。
  - 同一キー連打時の重なりをバッジ（×2, ×3...）で補助し、ラスト1打を `×1` で予告。
- **和音グルーピング (`ChordVisualRenderer`)**:
  - 同時に押すキーを最小全域木（MST）で結ぶ **和音リンク (Chord Link)**。
  - 同時押しキー群の外周を薄い枠で囲む **和音ハロー (Chord Halo)**。
- **ジャスト演出 (`TimingEffectRenderer`)**:
  - 打鍵ジャストタイミング（±80ms）でのインパクトフラッシュ、二重リング、および外側へ弾ける衝撃波紋（リップルアニメーション）。
- **カウントダウン演出**:
  - 曲冒頭に "3", "2", "1", "START" の大型カウントダウン表示。再生速度に連動した負の仮想時間により、0msで曲頭ノートがジャスト到達。

### 6.3 フローティング操作コントローラー (`ControlOverlayView`)
- タッチ操作可能なフローティング小窓（`FLAG_NOT_FOCUSABLE`）。
- **再生制御**: 再生 / 一時停止 / 停止、10秒巻き戻し / 10秒早送り、シークバーによる任意位置ジャンプ。
- **再生速度変更**: 0.25x 〜 2.0x（0.05刻み）のリアルタイム動的変更。
- **楽曲切り替え**: 透過小窓アクティビティ（`OverlayFilePickerActivity`）を呼び出し、ゲームを閉じずに別楽曲を選択。
- **最小化機能**: アイコンサイズのフローティングバブルに縮小。画面端へスナップ＆ドラッグ移動可能。

### 6.4 設定保存 (`SettingsRepository`)
- Android 標準の `SharedPreferences` を使用し、以下の設定を永続化:
  - 最後に選択した楽曲URI
  - 再生速度、ノート先読み時間、タイミングサークル先読み時間、カウントダウン時間
  - キー配置プロファイル (`FitProfile` JSON)
  - ビジュアル設定 (`VisualConfig`: ガイド円半径、各ノート色、各エフェクト表示ON/OFF)
  - MIDIマッピング設定 (`MidiMappingSettings`: AUTO/MANUAL、ルート音、スケール、オクターブ)
